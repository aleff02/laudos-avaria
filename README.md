# Laudos de Avaria — dados

Base de dados do app **Laudo de Avaria** (https://aleff02.github.io/claudinho/laudo/).

- `laudos/AAAA-MM/PROTOCOLO.json` — um arquivo por laudo (placa, loja, avarias, status)
- `fotos/AAAA-MM/` — fotos das avarias

Não edite à mão; use o painel (`…/laudo/#painel`) para mudar status e exportar Excel.
